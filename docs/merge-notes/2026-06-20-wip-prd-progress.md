## 3. 当前 WIP 进度总结

### 3.1 新增功能/改动

- UI 简化：结果页统计卡片与过滤交互合并、来源展示区精简、额外页面默认折叠。
- PDF 自动抓取：新增服务器端尝试下载 PDF、从 PDF 中抽正文并喂给 Gemini。
- 源文件手动上传：支持用户上传 PDF/DOCX/TXT 作为兜底核查路径。
- Gemini 核查策略改为三段式：全文大意 → 关键词扫描 → 定位引用。
- 模型选项与案例 PDF 直达链接增强：修复 Gemini 模型停用问题并增加判决书 PDF 快捷查看。

### 3.2 现有缺陷与风险

- PDF 自动抓取依赖目标站可直接下载，并且当前本地沙箱环境未能做真实外网抓取验证。
- URL 直接抓取仍然空缺，意味着含网页链接的引用仍未真正落地。
- 差异高亮缺失，PRD 里“对比结果可视化”仍未完成。
- 叙述性脚注/非引用识别尚为启发式，存在误判风险。
